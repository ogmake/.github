# ogmake

**OG images and social cards from one URL.** ogmake is an image API and editor that generates Open Graph previews for every page of your site. Free plan includes 100 images per month.

[Website](https://ogmake.com) · [Docs](https://ogmake.com/docs) · [Pricing](https://ogmake.com/pricing) · [Quickstart](https://ogmake.com/docs/quickstart) · [support@ogmake.com](mailto:support@ogmake.com)
